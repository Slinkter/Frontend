## 🎯 ¿Cómo usar estas guías?

1. **Lectura de Conceptos**: Cada guía desglosa los conceptos teóricos para que no te sorprendan términos como *Tokenomics*, *MCP*, *SDD* o *Harness Engineering*.
2. **Búsqueda de Tutoriales**: Cada módulo incluye **términos exactos de búsqueda para YouTube y Google** junto a los canales y documentaciones recomendadas.
3. **Talleres de Calentamiento**: Incluye código fuente listo para probar en tu terminal y en este repositorio antes de iniciar las clases.
4. **Proyecto de Portafolio**: Ambas guías están conectadas con este proyecto base ([`typescript01`](../README.md)) para que lo utilices como base de tu trabajo final.
