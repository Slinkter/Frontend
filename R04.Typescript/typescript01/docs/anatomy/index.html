Arquitectura del Sistema como Máquinas Físicas

Bajo el principio "The object is the explanation" de la skill Anatomy, los componentes arquitectónicos de este proyecto se han materializado en instrumentos físicos de precisión ordenados de menor a mayor complejidad.
